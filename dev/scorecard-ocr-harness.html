Clarity Scorecard OCR — dev harness

Load a photo of a scorecard and press Scan. There is no corner-stretch step — that is the point of this reader. It runs on the image as given, makes its strips, works out which one holds the hole numbers, and hands a grid to the same gd-scorecard-parse-core the club-website path uses. If it cannot read the card it says which stage stopped it instead of asking you to drag anything.
