## What changed

### 1. Restored slope / playing-distance render wiring
- Rewired slope / playing distance as a first-class shot-card metric.
- Added `gdRenderShotCardSlope(tilePlays, slopeData)` and now computes `slopeData` once inside `renderShot()` from the current start + active bubble/landing target.
- The old `.gdSlopeAdjustedLine` path is no longer cleared during normal render in a way that wipes the live slot.
- The slope slot starts blank if the live elevation call has not returned or fails.
- When the elevation call resolves, the existing async rerender path repopulates the slot.
- Added gated debug logging behind `window.gdSlopeCardDebug` only.

### 2. Added locked-in toolbar
- Added a compact `#gdLockedToolbar` that appears only when the shot frame is locked.
- Toolbar includes:
  - Green / landing zoom toggle
  - Unlock
  - Reset bubble
  - Compact slope / playing-distance display mirror
- Normal shot card is hidden while locked so map space is cleaner, but the slope value still has a compact locked-in home.

### 3. Added Green / Landing Zoom mode
- Added `gdToggleLandingZoom()`.
- When activated while locked:
  - Saves current locked camera view.
  - Zooms/pans into the active bubble / landing zone / green.
- When deactivated:
  - Restores the previous locked-in camera view.
  - Does not clear shot state, bubble, pin, club, or slope data.

### 4. Changed lock-in framing priority
- Added a final override for `frameShotView()` so locked framing prioritises the active landing/green/bubble area instead of forcing origin + target into frame.
- The origin/start point may now be outside the visible locked frame, matching the product direction.

### 5. Reduced tile seam / filter artefacts
- Added CSS overrides to stop lock-in/focus effects applying filters to Leaflet tiles or tile panes.
- Replaced per-tile darkening with a viewport-level overlay treatment.
- This should reduce black tile/grid seam artefacts in normal, locked, and landing-zoom modes.

### 6. Hid green outlines in locked user-facing play
- Locked mode now hides green labels/edge labels/remaining labels from the user-facing play view.
- Green geometry remains available internally for Wand, edge metrics, landing zoom, and future hole-frame logic.

### 7. Added lightweight active play session persistence
- Added `gd_active_play_session_v2` localStorage persistence for active GPS/play state.
- Saves course, current hole, start, target, green centre, pin, mode, lock state, camera, and landing zoom return view.
- Restores the last active shot session when returning to GPS if there is no current active shot.
- This is a lightweight bridge, not a full round archive/new-round prompt system yet.
