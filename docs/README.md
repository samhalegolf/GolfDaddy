# Clarity Caddy Documentation

This folder contains the operating documents for Clarity Caddy.

## Folder Roles

### architecture/

Authority documents. Read these before editing code.

Key files:
- `CLARITY_CADDY_TRUTH_FILE.md`
- `SYSTEM_MAP.md`
- `PROTECTED_SYSTEMS.md`
- `GPS_STABILISATION_PLAN.md`
- `GPS_PLAY_BEHAVIOUR.md`

### reports/

Evidence and patch history. These explain what was audited or changed.

### prompts/

Reusable operating prompts for audits, patches, and custody verification.

## Rule

Architecture docs are authority. Reports are evidence/history. Prompts are reusable instructions.

If code conflicts with the Truth File, audit first. Do not assume legacy behaviour is intentional.
